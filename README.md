## 🚀 Featured project

### 🛰️ Astronaut Health Monitor

An interactive dashboard that monitors **7 vital signs** for astronauts on long-duration missions — built for the **NASA Space Apps Challenge**. Live charts, three mission scenarios (Nominal / EVA / Emergency), an interactive body map, CSV export, and three themes.
